## Technological Stack

| Area              | Current state                                                                         |
| ----------------- | ------------------------------------------------------------------------------------- |
| Framework         | Angular 20 standalone application                                                     |
| Package manager   | pnpm (`pnpm-lock.yaml`)                                                               |
| Entry point       | `src/main.ts`                                                                         |
| Main UI           | `src/app/app.component.ts`                                                            |
| Purpose           | Personal résumé, experience, education, skills, projects, interests, and social links |
| Styling           | Custom CSS with responsive sidebar and dark/light theme support                       |
| Deployment output | `dist/angular-site`                                                                   |
| Static content    | `assets/` images/icons and `documents/` résumés, certificates, and learning materials |
