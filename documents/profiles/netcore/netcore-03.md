## (1) About the job

Ascendum is seeking a **Senior Full Stack .NET Developer** to support a modernization effort for a healthcare-focused client.

This role centers on maintaining and evolving a hybrid technology stack that includes:

- Legacy .NET Framework applications.
- Modern .NET 8 services.
- ASP.NET MVC and AngularJS modules being migrated to Angular 20.

This is a hands-on individual contributor role. You should be comfortable taking initiative despite sometimes receiving limited direction. You should also be prepared to become familiar with the system quickly and suggest improvements when opportunities are identified.

You will join an Ascendum team that is already supporting this modernization effort. You will be expected to ramp up quickly and collaborate with teammates on both the client and Ascendum sides.

## (2) Responsibilities

Responsibilities include, but are not limited to:

- Design, develop, and maintain C# applications across .NET Framework 4.8 and .NET 8.
- Support and modernize ASP.NET MVC Razor and ASP.NET Web API applications, including migrating patterns and practices to .NET 8 when needed.
- Develop and maintain Entity Framework 6 and Entity Framework Core code, including:
  - Database migrations.
  - Performance tuning.
  - Query diagnostics.

- Write and optimize SQL Server:
  - Queries.
  - Indexes.
  - Stored procedures.

- Troubleshoot database performance issues using execution plans and profiling tools.
- Maintain and modernize AngularJS applications.
- Contribute to migrations from AngularJS to Angular 20, with a strong focus on TypeScript and integration with .NET APIs.
- Deploy and support applications hosted in IIS, including understanding load-balancing and authentication implications.
- Build, maintain, and troubleshoot background-processing solutions using:
  - Windows Services.
  - Windows Scheduled Tasks.

- Work effectively when requirements are incomplete or evolving by:
  - Identifying necessary work.
  - Validating assumptions.
  - Proposing solutions.

- Become familiar with existing codebases to:
  - Understand application behavior and business logic.
  - Identify technical debt.
  - Recommend reasonable improvements.

- Collaborate productively with developers, QA engineers, and client stakeholders to determine task priorities and execution.
- Participate in agile ceremonies while remaining productive when backlog refinement is limited.

## (3) Minimum qualifications

- Eight or more years of experience using C# and the Microsoft technology stack.
- Recent hands-on experience working with both:
  - .NET Framework 4.8.
  - Modern .NET.

- Strong experience with ASP.NET MVC Razor and ASP.NET Web API.
- Demonstrated experience with Entity Framework 6 and Entity Framework Core, including:
  - Migrations.
  - Performance troubleshooting.

- Experience with SQL Server, including:
  - Indexing strategies.
  - Query and database performance troubleshooting.

- Experience maintaining or migrating AngularJS applications to modern Angular.
- Strong understanding of IIS-hosted applications and Windows-based deployment and execution models.
- Experience implementing and supporting background jobs using:
  - Windows Services.
  - Windows Scheduled Tasks.

- Proven ability to work independently in loosely defined environments.
- Ability to take initiative without requiring detailed task breakdowns.
- Ability to read and understand large, unfamiliar codebases.
- Experience working in agile teams using Git-based version control.
