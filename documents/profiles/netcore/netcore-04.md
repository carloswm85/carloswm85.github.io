## (2) Key responsibilities

- Design, develop, and maintain scalable back-end applications using C#, .NET Framework, and .NET Core.
- Build and maintain RESTful APIs, ASP.NET MVC applications, and WCF services.
- Develop efficient database solutions using Microsoft SQL Server and support integrations with MySQL.
- Write clean, maintainable, and well-tested code using NUnit and MSTest.
- Design and implement microservices-based architectures for modern applications.
- Collaborate with front-end developers to integrate APIs with web applications.
- Participate in Agile Scrum ceremonies, sprint planning, code reviews, and technical discussions.
- Manage source code using Git and GitHub while following best development practices.
- Contribute to cloud-native solutions and application deployments on Microsoft Azure.
- Troubleshoot production issues and continuously improve application performance, security, and reliability.

---

## (3) Required qualifications

- Bachelor's degree in Computer Science, Software Engineering, or a related field (or equivalent professional experience).
- 5+ years of experience in back-end software development using C# and .NET.
- Strong experience with .NET Framework, .NET Core, Entity Framework, ASP.NET MVC, Web API (RESTful), and WCF.
- Experience writing unit tests using NUnit and MSTest.
- Strong knowledge of Microsoft SQL Server and familiarity with MySQL.
- Working knowledge of HTML, CSS, JavaScript, with familiarity in jQuery and Vue.js.
- Experience using Git and GitHub for version control.
- Experience with Node.js and Python.
- Hands-on experience with Microservices Architecture.
- Experience deploying or supporting applications on Microsoft Azure.
- Experience working in Agile Scrum environments.
- Strong analytical, problem-solving, and communication skills.
- Professional English communication skills.

## (4) Preferred qualifications

- Experience with CI/CD pipelines and DevOps practices.
- Familiarity with cloud security and application performance optimization.
- Experience building highly available, enterprise-scale applications.
