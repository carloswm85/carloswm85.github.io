## Responsibilities

### AI-first development

- Partner effectively with agentic AI tools in daily coding and development workflows.
- Apply context engineering practices to improve collaboration with AI tools and teammates.
- Use software architecture principles and design patterns to produce maintainable, scalable code.
- Propose solutions that evolve and improve the architecture within the team's domain.

### Full stack — end-to-end ownership

- Design and implement solutions across the full stack:
  - Frontend: UI/UX.
  - Backend: APIs and services.
- Ensure seamless integration across layers, delivering cohesive features from data to user interface.
- Design APIs aligned with frontend needs.
- Deliver complete, production-ready features.

### Delivery and collaboration

- Own small to medium-sized features from planning through delivery.
- Create implementation plans and coordinate execution.
- Mentor other engineers through code reviews and technical guidance.
- Collaborate with product owners and stakeholders to translate requirements into technical solutions.

## Requirements

### Experience and technical stack

- 3+ years of experience building and shipping full-stack applications.
- Frontend:
  - React.
  - Or similar frameworks such as:
    - SolidJS.
    - Vue.
    - Angular.
- Backend:
  - C#.
  - .NET 6+.
  - ASP.NET Core.

### Engineering practices

- Experience designing and maintaining automated tests.
- Strong understanding of:
  - Software architecture.
  - Design patterns.
  - Technical trade-offs.

### Ways of working

- Experience with AI-assisted development using agentic tools as part of daily practice, such as:
  - Claude Code.
  - Cursor.
  - Antigravity.
- Ability to own features end-to-end.
- Ability to create implementation plans and coordinate delivery.
- Strong problem-solving skills.
- Ability to work independently and collaboratively in a fast-paced environment.

### Language

- Strong written and spoken English.
- Intermediate level or above.
