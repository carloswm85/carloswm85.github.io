## (1) Sobre Ayi Group

Somos **Ayi Group**, una empresa que brinda servicios, productos y distintas soluciones de tecnología de la información. Contamos con más de 20 años de experiencia en proyectos locales e internacionales.

Si estás buscando formar parte de un grupo dinámico, inquieto, colaborativo y orientado hacia la mejora continua, este es tu lugar. **¡Sumate!**

Nuestro propósito es **transformar realidades mediante la cocreación de soluciones de alto impacto**.

---

## (2) Descripción del puesto

Como **Backend Semi Senior Software Engineer**, serás una parte fundamental del equipo de desarrollo.

Tendrás la oportunidad de diseñar y desarrollar aplicaciones de alta calidad utilizando tecnologías modernas como **Node.js** y **.NET**.

Buscamos un profesional con experiencia sólida en la optimización del rendimiento de aplicaciones y que comparta nuestras mejores prácticas de desarrollo y codificación.

---

## (3) Funciones y responsabilidades

- Desarrollar aplicaciones de alta calidad utilizando las tecnologías mencionadas.
- Mejorar continuamente el rendimiento de las aplicaciones.
- Implementar buenas prácticas de codificación y realizar revisiones constantes del código.
- Integrar y desarrollar APIs eficientes para garantizar el correcto funcionamiento de las aplicaciones.
- Crear documentación clara y precisa que facilite la comprensión y el uso del software desarrollado.

## (4) Requisitos técnicos

### (4.1) Requisitos excluyentes

- Experiencia en el desarrollo de APIs REST utilizando **ASP.NET Core 8 o superior**.
- Experiencia en arquitecturas de microservicios.
- Experiencia en integraciones con servicios REST.
- Conocimientos de bases de datos relacionales, especialmente **SQL Server**.
- Experiencia en la implementación de pruebas unitarias.
- Experiencia trabajando con metodologías ágiles, especialmente **Scrum**.
- Al menos tres años de experiencia en posiciones similares.

### (4.2) Requisitos deseables

- Experiencia con el ORM **Dapper** para .NET.
- Experiencia con metodologías de desarrollo como **TDD** o **BDD**.
- Experiencia con el framework **NestJS** para Node.js.
- Conocimientos de bases de datos NoSQL, como:

  - MongoDB.
  - Redis.

- Conocimientos de **Docker** y **Kubernetes** para el despliegue de aplicaciones.
- Experiencia con herramientas de integración y entrega continuas, como:

  - Azure Pipelines.
  - GitHub Actions.

- Experiencia utilizando la plataforma **Microsoft Azure**.
- Experiencia con sistemas de mensajería y arquitecturas distribuidas modernas, como:

  - Azure Service Bus.
  - RabbitMQ.
  - Apache Kafka.
